
## 4. Материалы для студентов

### Что выдаётся студентам

* Все файлы из каталога `Materials for students`
* Скрипт `client.sh`

### Инструкция для студентов

* Использовать `Installation instructions.html`
* Следовать пошаговой установке

### Что делает client.sh

* Устанавливает SSH-клиент (при необходимости)
* Создаёт пользователя `linuxoid` с правами sudo
* Устанавливает SSH-ключ
* Скачивает лабораторную работу
* Запрашивает ФИО и группу
* Добавляет функцию `labserver`

### Результат установки

* Шаблон для выполнения лабораторной работы (worklab) находится в `/home/linuxoid`

# Установка серверной части Linux Lab

### Требования

* Linux-сервер
* Docker и docker-compose
* Root-доступ

### Установка n8n

* Установить n8n (например, на хостинге Beget)
* Проверить, что n8n доступен и запускается через Docker

### Размещение серверных скриптов

* Скопировать **содержимое** каталога `on the server` в `/usr/local/bin/custom_scripts`

### Инициализация сервера

* Выдать права на выполнение `server.sh`
* Выполнить `sudo ./server.sh`
* В процессе:

  * создаётся пользователь `admeen`
  * настраиваются группы и права
  * генерируется SSH-ключ
  * приватный ключ встраивается в `client.sh`
  * разворачиваются каталоги `/home/admeen/scripts` и `/home/admeen/verification`
